# Yuwei Miao Academic Homepage

This repository contains a static academic website for GitHub Pages.

## Structure

- `index.html`: homepage
- `publications.html`: publications list
- `projects/`: project overview and individual project pages
- `assets/css/style.css`: shared styling
- `assets/js/main.js`: optional JavaScript
- `assets/images/`: portrait and project images
- `cv/Yuwei_Miao_CV.pdf`: downloadable CV
- `data/publications.json`: structured publication metadata

## Preview locally

### Option 1
Open `index.html` directly in your browser.

### Option 2
Run a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deploy to GitHub Pages

1. Create a repository named `YOUR_USERNAME.github.io`
2. Upload all files in this folder to the repository root
3. Commit and push
4. Open `https://YOUR_USERNAME.github.io`

## Replace placeholders

Search for:

- `YOUR_GITHUB_LINK`
- `YOUR_GOOGLE_SCHOLAR_LINK`
- `YOUR_LINKEDIN_LINK`
- `YOUR_*_PAPER_LINK`
- `YOUR_*_CODE_LINK`

and replace them with real URLs.
